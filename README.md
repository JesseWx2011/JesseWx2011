## My Story
In April 2023, I was able to get my hands on a laptop. A [Dell Inspiron 3511](https://www.dell.com/en-us/shop/cty/spd/inspiron-15-3511-laptop) with a strong-enough CPU for comfortable coding. It was $349 when purchased. The very next month, I discovered the world of coding. My dream was to create a weather-website I enjoyed visiting every day. I created my GitHub on May 20, 2023, and called it _"JesseLikesWeatherakaYoshiKart"_. (I would later change this name.)

I continuously made several attempts to make my dream work, watching numerous YouTube videos and copying-pasting code I found online. But none of it worked out for me, even if it was fully-functioning and working. In September 2023, I discovered a software called [Weather Display](https://weather-display.com), created by Brian Hamilton, it could send weather data to a weather website.

I downloaded Ken True's [Base-USA](https://saratoga-weather.org/wxtemplates/index.php#:~:text=USA%20languages%20included%3A) weather template and launched a [website](https://dinoswxreport.altervista.org/wp-content/wxindex.php) on a subdomain of [Altervista](https://en.altervista.org/). It came at a price though, I was running Weather Display off of my home laptop, so I had to leave it on at all-times for it to continue sending weather data continuously.

In January 2024, I discovered a video by [The Coding Train](https://www.youtube.com/thecodingtrain) on YouTube that taught me how to make JSON API requests and it was able to get me started on my weather website! (_Praise the Lord_) And on January 23, 2024, I created a repository called "[weather-dashboard](https://web.archive.org/web/20240123184921/https://jessewx2011.github.io/weather-dashboard/)", it was a weather website that allowed you to search up any location with the AerisWeather API (now [Vaisala xWeather](https://www.xweather.com/)).

The code was terrible though, filled with "if/else" statements throughout the entire JavaScript part of the code. But it worked. I continued working on the project by adding a few more pages to it, before I made the last commit to the project in December of 2024. In 2025, I discovered Cursor, an AI code software that could build entire websites.

I tested it out by giving a detailed prompt to build a weather website, similar to the website [saratoga-weather.com](https://saratoga-weather.com). The end result blew me away.

<img align="center" width="1919" height="924" alt="Milton Weather Page image from April 11, 2025" src="https://github.com/user-attachments/assets/aa9ce330-0ad2-4baa-b86c-527d9604cae3" />

And so I launched the Milton Weather Page on April 11, 2025. I continued to integrate AI features into a majority of my projects. I continued to add page after page to the website, and it was receiving a number of visits per day, especially on major weather event days. The site was hosted off of GitHub Pages. I started working with Python in September 2025.

On New Years Day 2026, I moved the site under a [Vercel](https://vercel.com/) domain, which helped the site load much faster compared to GitHub pages. In October 2026, I was able to move my website under an official domain: [https://weather.windowclean.net](https://weather.windowclean.net). Consequently, I wasn't able to get started on the site immediately, having Hurricane Isaias left my region in peril. The site owner also explicitly asked that no AI-generated code would be on the site.

But I was able to make a good, functional weather website off of it, and it launched on October 30, 2026. I continue to improve on my personal coding skill to this day.
